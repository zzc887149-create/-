## 源文件与流程

源文件仍为根目录 `赵雷2026_鸟巢_座位图内场版.blend`。

运行 `refine_foh_controls_v27.py`，复用 `audit_field_details_v26.py` 检查通道，再执行 `export_repaired_architecture_v6.py`、`report_export_geometry_v27.py`。Unity 执行 `ZhaoLeiBirdsNestV3.ValidateFohControls.Deliver`，完成重建、材质验证、截图及 Windows 构建。最后运行 `package_enhanced_delivery.py`。

本机为节约 C 盘空间，将 `unity_enhanced/WindowsPreview_v27` 建成目录联接，实际程序保存在 `D:/赵雷鸟巢_预览/WindowsPreview_v27`。根目录固定观看快捷方式和完整预览 ZIP 的使用方法不变；GitHub 工程不依赖这个本机联接，其他电脑构建时会创建普通输出文件夹。
